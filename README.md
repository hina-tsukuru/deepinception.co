# deepinception.co

DeepInception の Web サイト（GitHub Pages で公開）。

| ファイル | 内容 |
|---|---|
| `index.html` | トップ（紹介・アプリ・連絡先） |
| `privacy.html` | プライバシーポリシー（日本語 / English） |
| `404.html` | 見つからないページ |
| `style.css` | スタイル（外部リソースなし、ダークモード対応） |
| `favicon.svg` | ブラウザのタブに出るアイコン |
| `CNAME` | カスタムドメイン `deepinception.co` |

## 方針

- 本名・住所は載せない。運営者表記は DeepInception、連絡先は `contact@deepinception.co`
- 外部の解析ツール・広告・フォント・CDN は使わない（プライバシーポリシーと矛盾させないため）
